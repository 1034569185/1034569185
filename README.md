# TextReader - 文本阅读器

一个简洁优雅的文本阅读器，参考 [Koodo Reader](https://github.com/koodo-reader/koodo-reader) 设计，专为舒适阅读体验而设计。

## 功能特点

- 📖 **支持多种文本格式**: TXT, MD, HTML, LOG 等
- 🎨 **自定义字体**: 支持系统所有字体，可调节字号和粗细
- 🌈 **12种精选护眼主题**: 羊皮纸、护眼绿、深夜模式、薄荷绿等
- 🎯 **自定义颜色**: 可自由选择背景色和文字颜色
- 📊 **阅读统计**: 字数统计、阅读进度、预计阅读时间
- 📏 **排版设置**: 行间距、段落间距可调
- 🔖 **书签功能**: 支持添加和管理书签
- 📜 **自动滚动**: 解放双手的自动滚动功能
- 🖥️ **全屏模式**: 沉浸式阅读体验
- 💾 **自动保存**: 自动保存阅读位置和设置
- 🖥️ **4K/高DPI支持**: 完美适配高分辨率屏幕
- 🔍 **搜索结果预览**: 搜索结果显示上下文片段，支持分页
- 📚 **智能目录**: 自动识别章节，支持过滤搜索
- 🔧 **界面缩放**: 支持 80%-200% 界面缩放

## 自动目录功能

TextReader 可以自动识别小说章节并生成目录，支持以下格式：

| 格式 | 示例 |
|------|------|
| 中文章节 | 第一章、第1章、第一节、第一回、第一卷 |
| 英文章节 | Chapter 1、CHAPTER 1 |
| 数字标题 | 1. 标题、1、标题 |
| 特殊标记 | 【标题】 |
| 特殊章节 | 序章、序、前言、楔子、尾声、番外、后记 |

点击目录中的章节标题可快速跳转到对应位置。

**智能定位**: 打开目录时，会自动滚动到当前正在阅读的章节，并高亮显示。

## 搜索功能

- **实时搜索**: 输入关键词即时显示结果
- **结果预览**: 搜索结果显示上下文片段，高亮关键词
- **分页浏览**: 搜索结果支持分页，可直接输入页码快速跳转
- **渐进式搜索**: 大文件搜索不会卡顿

## 安装和运行

### 系统要求
- Python 3.6 或更高版本
- Tkinter (通常随 Python 一起安装)

### 运行方法

```bash
# 直接运行
python text_reader.py

# 或者添加执行权限后运行 (Linux/Mac)
chmod +x text_reader.py
./text_reader.py
```

### Windows 用户
直接双击 `text_reader.py` 文件即可运行，或者在命令行中：
```cmd
python text_reader.py
```

## 使用说明

### 打开文件
1. 点击工具栏的"📂 打开"按钮
2. 或使用菜单 文件 → 打开
3. 或使用快捷键 Ctrl+O
4. 支持 UTF-8, GBK, GB2312 等多种编码

### 调整字体
1. **快速调节**: 使用工具栏的字号和字体选择器
2. **详细设置**: 菜单 → 设置 → 字体设置
3. **快捷键**: Ctrl+ +/- 快速增减字号

### 更换主题
1. 使用工具栏的主题下拉菜单选择预设主题
2. 或点击"🎨 背景"和"🖌️ 文字"按钮自定义颜色
3. 也可通过 菜单 → 设置 → 颜色设置 进行详细调整

### 书签功能
1. 阅读时按 Ctrl+B 添加书签
2. 通过 菜单 → 导航 → 管理书签 查看和跳转书签

### 自动滚动
点击工具栏的"▶ 自动滚动"按钮开启自动滚动，再次点击停止。

## 配置文件

设置自动保存在用户主目录下的 `.textreader_settings.json` 文件中，包括：
- 字体设置
- 颜色设置
- 最后打开的文件
- 阅读位置
- 书签
- 最近文件列表

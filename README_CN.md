### 4. 小顶堆特性

小顶堆是一种完全二叉树，具有以下特性：
- **堆属性**：每个节点的值都小于或等于其子节点的值
- **根节点**：最小元素总是位于根节点位置
- **完全二叉树**：除最后一层外，其他层都是满的，最后一层从左到右填充
- **常见应用**：优先队列、堆排序、任务调度等

4. 将所有图片保存到`image`目录

## 技术实现

### 核心算法
- **堆化上浮（heapify_up）**：新元素插入后，与父节点比较并上浮，维护小顶堆性质
- **堆化下沉（heapify_down）**：删除根节点后，将最后一个元素放到根位置并下沉，维护小顶堆性质

### 可视化技术
- 使用`networkx`构建树形图结构
- 使用`matplotlib`绘制节点和边
- 自定义层次化布局算法，确保树形结构清晰美观
- 节点用浅蓝色圆圈表示，边用灰色线条连接
